# 一进二失败率归因分析（2026-10-21 ~ 11-04，38 个样本）

> 数据源：`股票/<date>/report.json` 的 `review.prev_list`（每个交易日对前一日名单的逐只回填），
> 共 9 个可回填交易日、38 只候选、11 只晋级。
> 口径：**晋级 = 次日进入涨停池**（`outcome=advanced`），与「能不能买到」无关（可交易性单列）。

## 一、结论先行

1. **失败率 71% 不是选股失效，是首板这个物种的基准**：全市场「昨首板 → 今涨停」的基准是 **16.4%**（42/256），
   名单是 **29.2%**（7/24，同期可比），**超额 +12.8pct**。也就是说：85% 的首板次日都会失败，名单把它压到 71%，
   这已经是有效但很有限的改进。
2. **最强的解释变量是「板块次日家数腰斩/归零」**：健康板块 70%（7/10）晋级，腰斩/归零只有 **9.5%**（2/21），
   Fisher p=0.0013。但它是**结果变量**，不是买入前可得的信息。
3. **分数与结果不相关，A 级甚至低于 B 级**：A 22.7%（5/22）vs B 36.4%（4/11），90 分以上 0/4。
   p=0.44 不显著，但至少可以否定「A 级更该打」这个前提。
4. **事前可得的板块趋势几乎没有区分度**：用 P 日 vs P-1 日家数，扩张 50%（4/8）、持平 20%（1/5）、新起 25%（3/12）、
   已衰减 0/2，p=0.52。这条很关键——它否定了现有一条拟议规则的落地方式（见第四节）。

## 三、分维度拆解

### 3.1 板块次日变化（唯一显著因子）

| 板块家数（次日 vs 名单日） | 晋级/样本 | 命中率 |
|---|---|---|
| 扩张 | 3/4 | 75.0% |
| 持平 | 2/3 | 66.7% |
| 收缩 | 2/3 | 66.7% |
| 腰斩（<60%） | 1/8 | 12.5% |
| 归零 | 1/13 | 7.7% |

健康（扩张/持平/收缩）合计 **7/10 = 70%**；腰斩/归零合计 **2/21 = 9.5%**，**Fisher p = 0.0013**。
失败样本 27 只里 19 只（70%）落在腰斩或归零的板块。这与 R-OBS-10 的历史观察一致，但样本从 13 扩到 21、结论更稳。

### 3.2 评分与评级（**不是单调关系**）

| 分数段 | 晋级/样本 | 命中率 |
|---|---|---|
| 60–69 | 2/5 | 40.0% |
| 70–79 | 5/16 | 31.2% |
| 80–89 | 4/13 | 30.8% |
| 90–100 | 0/4 | **0.0%** |

A 级 **5/22 = 22.7%**，B 级 **4/11 = 36.4%**（p=0.44）。分数越高命中越低，虽然不显著，但「A 级优先」没有任何证据支持。

### 3.3 位置（方向与现有规则相反）

| 60 日分位 | 晋级/样本 | 命中率 |
|---|---|---|
| 0–0.4 | 1/6 | 16.7% |
| 0.4–0.7 | 2/13 | 15.4% |
| 0.7–0.9 | 1/3 | 33.3% |
| 0.9–1.0 | 5/11 | **45.5%** |

高分位（≥0.7）**6/14 = 42.9%**，低分位 **3/19 = 15.8%**（p=0.122）。
而 `R-SCORE-01` 的位置维度给 0.4~0.8 最高分（+15）、>0.9 只给 +5——**方向正好相反**。
（解释：高位股多为连板接力票，次日惯性更强；低位票缺乏关注度。样本仍小，先转观察。）

### 3.4 封单占比（方向也相反）

| 封单/流通 | 晋级/样本 | 命中率 |
|---|---|---|
| 0.3–1.0% | 6/15 | 40.0% |
| 1.0–2.0% | 3/16 | 18.8% |
| ≥2.0% | 0/2 | 0% |

封单越厚、次日越差（p=0.239）。合理解释：封单大的票次日容易一字高开，高开即兑现；而 0.3~1% 的「弱封」反而换手充分、次日有承接。

### 3.5 末封时间（非单调）

| 末封 | 晋级/样本 | 命中率 |
|---|---|---|
| ≤10:00 | 5/17 | 29.4% |
| 10:00–13:00 | 1/8 | **12.5%** |
| 13:00–14:00 | 3/8 | **37.5%** |

「越早封越好」不成立；10–13 点最差、13–14 点最好（各 n=8，噪声大，但足以说明 R-POOL-02 的 14:00 线缺乏依据）。

### 3.6 流通市值

| 流通市值 | 晋级/样本 | 命中率 |
|---|---|---|
| ≤30 亿 | 3/9 | 33.3% |
| 30–60 亿 | 5/15 | 33.3% |
| 60–100 亿 | 0/4 | 0% |
| 100–200 亿 | 0/3 | 0% |
| ≥200 亿 | 1/2 | 50% |

60~200 亿 **0/7**，小市值（≤60 亿）**8/24 = 33%**。与 `R-SCORE-01` 筹码维度（≤60 亿 +10）方向一致，
但与已废除的「30~100 亿硬门槛」不一致——门槛确实该废，软偏好该保留且可以更强。

### 3.7 量比、炸板次数、换手率（无区分度）

- 量比：0.5–5 倍各档命中 23%~50%，无单调关系；
- 炸板 0 次 29.6%（8/27）vs 1 次 27.3%（3/11），几乎无差；
- 换手：0–5% 29.4%、5–10% 26.7%，`R-POOL-06` 的 3~15% 区间没有体现出边界效应。

## 四、现有规则体检

### 4.1 明确有问题（建议改）

| 规则 | 问题 | 证据 |
|---|---|---|
| **R-SCORE-01 位置维度** | 方向与数据相反：规则奖励低分位，数据奖励高分位 | ≥0.7 命中 42.9% vs <0.7 15.8% |
| **R-SCORE-03 + R-ENV-02「半仓只打 A 级」** | A 级无优势甚至更差；「只打 A 级」会剔掉更好的票 | A 22.7% vs B 36.4%；90+ 0/4 |
| **R-EXT-04 周线扣分** | 对所有候选同时 −2，是**常数平移**：不改变排序，只把评级整体拉低 → 名为「评分修正」，实为「评级缩水」 | 38 只候选全部带同一条 `R-EXT-04 −2` |
| **R-OBS-10 的落地方式** | 设计是「P 日 vs P-1 日家数衰减 → 扣分」，但该**事前**信号无区分度 | 扩张 50% / 持平 20% / 新起 25% / 已衰减 0/2，p=0.52 |
| **R-POOL-02 末封 ≤14:00** | 单调性不成立，13–14 点段反而最高 | 见 3.5 |
| **R-POOL-04 封单 ≥0.3%** | 方向相反（封单越厚越差），阈值只是「别太薄」的下限，不是强度指标 | 0.3–1% 40% vs ≥1% 16.7% |
| **SKILL.md 的 N 字口径** | 与 RULES 冲突：写「回调 1~4 天、市值 30~100 亿、股价 3~20 元、倍量不再是硬门槛」，RULES 是「1~10 天、废除市值股价、倍量恢复硬门槛」 | 两处原文对照 |

### 4.2 没问题但需注意

- **R-ENV 闸门**：空仓日名单命中 30.4%（7/23）、半仓与正常各 20%（1/5）——闸门判的是「能不能做」，不是「名单好不好」，
  两者不该混为一谈；报告里把闸门和名单并排展示，容易让人误以为空仓日的名单更差。
- **R-SCORE-02 的 20cm −30**：与 R-POOL-01「剔除 20cm」重复，属于死代码（20cm 根本进不了池），不影响结果但增加阅读成本。

### 4.3 有证据支持、可加强

- 板块状态（唯一显著因子）→ 应升级为**执行层规则**（盘中可得），而不是入池前的扣分；
- 流通市值 ≤60 亿偏好（33% vs 0/7）→ 与现有筹码维度同向，可加权但不必设门槛。

## 五、提炼的新规则（已写入 RULES v1.26）

1. **R-EXEC-13 盘中板块家数闸**：开盘 30 分钟统计「同行业涨停数」，若 ≤ 昨日该行业涨停数的 60% 或已归零 →
   当日放弃该板块全部候选；已持仓者竞价出。这是把唯一显著因子（9.5% vs 70%）变成**可执行**规则。
2. **R-SCORE-05 评级去绝对化**：A/B 不再代表「可打/观察」，只代表**名单内相对排序**；
   「半仓只打 A 级」改为「只打**排序第一且板块健康**的一只」。理由是绝对分无预测力（90+ 0/4）。
3. **R-OBS-21 位置维度方向存疑**（观察）：高分位反而更好，样本 33 只，p=0.122，先记录不改分。
4. **R-OBS-22 封单反向**（观察）：封单越厚次日越差，样本 33 只，p=0.239，先记录不改分。

## 六、样本与置信度声明

- 总样本 38，A/B 分组仅 22/11，置信区间很宽；除「板块腰斩/归零」外，其余差异**均未达 p<0.05**。
- 本报告的用法是：**否定没有证据的规则**（如 A 级优先、位置低分位优先），而不是据此建立新的精确定量规则。
- 真正的样本积累方向：把每天的回填继续跑下去，到 100+ 样本再谈维度权重。
